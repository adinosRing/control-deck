# Earlier prototypes

- [Browser version](browser/INSTALL.txt) serves the original dashboard on the Kindle's loopback interface. It includes its Go server, scriptlets, and KUAL extension.
- [Offline native version](offline/INSTALL.txt) renders the original demo directly on the Kindle. The prototype includes its Go source and launcher.
- [Spotify companion](spotify/bridge.py) was the earlier Windows bridge. It used Windows media controls and Core Audio. Its [Python dependencies](spotify/requirements.txt) are included for reference. The current Kindle client sends YouTube commands and uses the companion at the repository root.

Build the Kindle binaries from source. The prototype backdrops use the same CSS robot illustration as the main project.
